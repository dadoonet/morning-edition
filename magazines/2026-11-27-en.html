1Password got breached. Your vault didn't.

An attacker got into an employee's GitHub account and pushed malicious code to backend services.

Dev tools · 264 points

minipg: PostgreSQL as a single executable.

No server to configure, no Docker. One folder holds the whole database.
# a .pgdb folder = data + config + Postgres version
minipg app.pgdb "select 1"
minipg run app.pgdb -- npm start
minipg run test.pgdb -- go test ./...
# server starts on demand, stops when idle

It embeds the postgres:18-alpine image and runs it in a tiny machine, so tools like psql start in about 90 ms. Runs on Linux and Apple Silicon.

Caveat from the author: it is early, about 2x slower than native, and not for data you can't recreate.

For youIdeal for disposable Postgres in Java integration tests or CI. Swap the `go test` line for `mvn test` and try it.

Weird science · 26 points

The Engineering of Smartphone Cameras

A DSLR lens is typically 50 to 150 millimetres long. The lens in your phone lives in roughly eight, with the sensor less than ten millimetres behind the first optical surface. Everything else in this essay follows from that constraint.

Plastic lenses make field curvature hard to fix, because the Petzval sum depends on element power and refractive index, and plastics offer very few indices to choose from. Aspheres cannot change it. That is why some designs sneak in a glass element or a rare in-between plastic.

The 5x telephoto cheats the geometry: its focal length is about 17 mm, folded through a rhomboid prism so light bounces four times. Moulded aspheres hold form errors near a tenth of a micron, yet are touchier about tilt and decentre.

† 5x module ≈ 120 mm equivalent, 20° field of view. Ultra-wide ≈ 13 mm, 120°.
